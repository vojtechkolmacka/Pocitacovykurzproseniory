Lokální pracovní nástroje

Důležité: Tato stránka není zabezpečená serverová administrace. U statického webu na GitHub Pages nelze bezpečně ověřovat heslo přímo v JavaScriptu. Změny uložené zde jsou pouze v tomto prohlížeči a nezobrazí se automaticky návštěvníkům.

Export studijního obsahu

Stáhne aktuální výuková data jako JSON, který lze archivovat nebo použít při další úpravě webu.

Import obsahu

Načte JSON exportovaný z tohoto webu do tohoto prohlížeče jako pracovní kopii. Nezmění veřejný web.

Jak bezpečně upravovat veřejný web

  1. Upravte zdrojové soubory v repozitáři GitHub.
  2. Změny nejprve otestujte na samostatné větvi nebo náhledu.
  3. Veřejný přístup k administraci s heslem uloženým v JavaScriptu nepoužívejte.
  4. Pokud chcete editaci přímo na webu s centrálním ukládáním, je nutný server nebo ověřená služba s pravidly přístupu (například Firebase/Supabase).
